# Govorun — ручной чек-лист перед релизом (нужен живой микрофон)

## Установка
- [ ] `installer\output\GovorunSetup-0.1.0.exe` ставится без прав администратора (per-user, `%LOCALAPPDATA%\Programs\Govorun`).
- [ ] Опция «Запускать при входе в Windows» создаёт ключ `HKCU\...\Run\Govorun`.
- [ ] (От админа) Опция «Запретить доступ в сеть» создаёт блокирующее правило в брандмауэре.

## Онбординг (первый запуск)
- [ ] Шаг 1: шкала реагирует на голос, мастер сам переходит дальше через ~1,5 с речи.
- [ ] Шаг 2: показывается «Govorun оптимизирован под ваш процессор (RTF ≈ N)».
- [ ] Шаг 3: выбор «двойной Ctrl» / «Ctrl+Space».
- [ ] Шаг 4: хоткей → сказать «Привет, Говорун» → хоткей → текст появился в демо-поле, статус «Получилось!».

## Управление
- [ ] Онбординг, шаг 3: выбор Ctrl+Win / Ctrl+Space / двойной Ctrl и режима toggle / push-to-talk.
- [ ] Ctrl+Win не открывает меню «Пуск» (клавиша Win проглатывается).
- [ ] Push-to-talk: зажал — идёт запись, отпустил — транскрибация; случайный короткий «клик» (<0,4 с) молча игнорируется.
- [ ] Трей → «Управление»: смена хоткея и режима на лету, галочки корректны.

## Оверлей
- [ ] При записи по центру внизу экрана появляется тёмная капсула с логотипом, полосками-эквалайзером (пляшут от голоса) и таймером.
- [ ] При обработке логотип пульсирует, полоски опадают; после вставки капсула исчезает.

## Диктовка
- [ ] Notepad: хоткей → речь → хоткей → текст вставлен с пунктуацией и заглавными.
- [ ] VS Code / браузер / мессенджер: то же.
- [ ] cmd.exe: текст «печатается» посимвольно (typing-fallback).
- [ ] Скопировать картинку (Win+Shift+S) → продиктовать текст → Ctrl+V вставляет исходную картинку (буфер восстановлен).
- [ ] Во время записи возле курсора виден пузырёк с осциллографом и таймером; при обработке точка синеет, иконка в трее пульсирует.

## Трей
- [ ] Иконка: серая (ожидание) → красная (запись) → пульсирующая синяя (обработка).
- [ ] «История» показывает последние 5 распознаваний, клик копирует в буфер.
- [ ] «Сменить горячую клавишу» переключает режим и показывает уведомление.
- [ ] «Выход» завершает процесс (проверить в диспетчере).

## Автономность и устойчивость
- [ ] Отключить сеть (Wi-Fi/кабель) → диктовка работает.
- [ ] Оставить в фоне на несколько часов → память процесса стабильна (лог `%APPDATA%\Govorun\log*.txt`, строки Watchdog).
- [ ] Повторный запуск exe не создаёт второй процесс (single instance).
- [ ] Хоткей во время обработки игнорируется, приложение не падает.

## Деинсталляция
- [ ] Удаление через «Приложения и возможности» подчищает `%LOCALAPPDATA%\Programs\Govorun`, ключ Run и `%APPDATA%\Govorun`.
